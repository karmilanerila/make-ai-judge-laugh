## How it works

`main.py` writes that single line (148 characters) to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
No network, no dependencies, no files besides the one line.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
